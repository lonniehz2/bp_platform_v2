3.1 不加密参数  
===== PAGE 5 =====
 
3.2 token 参数  
 见文档接口  4 ，根据  appKey 和  appSecret 来获取用户访问  token ； 
 注意 token 30 分钟过期，过期后需重新获取访问 
 
3.3 参数值加密  
 参数值加密采用的是  AES 加密（ AES 加密算法见附件，暂只提供  JAVA 版本供参考） 
 例如： 
  加密密钥为： pwd = token.substring(0,25);  
  // 密钥取  token 前  25 位： 5x41nO+EIYENqlj8FmG2XGXMa  
 
3.4 sign 请求参数签名生成规则  
 以下是生成  sign 签名举例：
  1 ）先对原来请求参数值进行加密：  
 对最后的请求参数按字典排序后组织成字符串进行  MD5 加密（ MD5 加密算法见附件，暂只提供 
JAVA 版本供参考）：
token = 5x41nO+EIYENqlj8FmG2XGXMaJqvMHJ3ERblxrZXPLq0myRG1aVZfjyEpShj rqiy; 1
    如对  userId 值加密： userId = 719B29DB1EF45F00D9C5CD320DAE6; 
    userId 加密为：  AES.encryptParam (pwd, userId); 
    结果为： FeBrmAMo+eO63Uuojon/x/1mlWlRhTVL3f+QtwKTEpo=
