[6] style='Body Text' :: 业主使用云门道小程序的步骤是怎么样的？
[7] style='Normal' :: 
[8] style='Body Text' :: 首先业主要登录云门道小程序，并完成实名认证。完成实名认证后就可以添加房屋或者车位，成为你的资产。最后可以添加家人、租客或者临时人员。如果有车位的话还可以添加车辆。
[9] style='Normal' :: 
[10] style='Normal' :: 
[11] style='Body Text' :: 哪些角色可以添加人员 ？
[12] style='Body Text' :: 业主可以添加家人、租客、临时人员、邀请访客；租客可以添加同住人、临时人员、邀请访客；家人可以邀请访客；同住人可以邀请访客。
[13] style='Normal' :: 
[14] style='Normal' :: 
[15] style='Body Text' :: 如何切换组织和角色？
[16] style='Body Text' :: 在云门道首页最上方，会显示您所在的组织名称。如果您有多个组织，可以点击下拉按钮来切换组织。切换角色也是一样的方式。

[18] style='Normal' :: 
[19] style='Body Text' :: 添加家人时提示添加用户未实名，请先实名怎么办？
[20] style='Body Text' :: 首先您添加的人员必须已经注册过云门道小程序。您需要让被添加的人员先去注册云门道小程序，再进行实名认证。最后您再把人员添加为家人。
[21] style='Normal' :: 
[22] style='Normal' :: 
[23] style='Body Text' :: 我要添加租客怎么办？
[24] style='Body Text' :: 首先您需要让租客注册云门道小程序，并且完成实名认证。然后您在云门道小程序人员授权时选择添加租客，输入租客实名认证过的手机号即可。
[25] style='Normal' :: 
[26] style='Normal' :: 
[27] style='Body Text' :: 我是访客，我该怎么操作？
[28] style='Normal' :: 
[29] style='Body Text' :: 搜索云门道小程序，在登录页面选择“我是访客 ”登录。登录成功后根据页面提示输入访客码（访客码为6位数字，由邀请人告知给您）。访客码添加成功后，您会在页面上看到门锁、梯控等设备信息，点击开门按钮即可。
[30] style='Normal' :: 
[31] style='Body Text' :: 如果家人没有手机号怎么办？
[32] style='Normal' :: 
[33] style='Body Text' :: 在添加家人时选择虚拟号码，家人可以通过虚拟号和验证码登录云门道小程序。
