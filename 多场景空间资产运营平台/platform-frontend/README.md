## 运行

当前复用老前端依赖目录做本地验证：

```text
platform-frontend/node_modules -> frontend/node_modules
```

启动：

```bash
npm run dev
```

构建：

```bash
npm run build
```

## 关键处理

- 后端 Long ID 统一序列化为字符串，避免 JS 大整数精度丢失。
- 项目选择保存在 `localStorage.platformProjectId`。
- 默认选择有合同/申请/设备数据的项目。
- 业务页面直接调用平台 API。
