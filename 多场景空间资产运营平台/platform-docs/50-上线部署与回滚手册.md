## 5. 部署

```bash
cd /home/luo/bp-platform-new
# 先备份当前 jar
cp multi-scene-platform.jar multi-scene-platform.jar.bak

# 上传新 jar 后
kill -9 $(ps -eo pid,args | awk '/[m]ulti-scene-platform.jar/ {print $1}')
nohup env DB_PASSWORD='***' SERVER_PORT=8090 \
  java -Xms512m -Xmx1024m -XX:+UseG1GC -Dfile.encoding=UTF-8 \
  -jar multi-scene-platform.jar > app.log 2>&1 < /dev/null &
```
