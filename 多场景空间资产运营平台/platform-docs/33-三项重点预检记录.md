## 3. 合同直接收款

### 3.1 已支持

```text
合同详情显示 3 笔未结清账单
打开“选择账单”弹窗
勾选一笔或多笔账单
按账单填写本次收款金额
自动计算本次合计
未选择账单时提示
金额超过未收时提示
确认后更新账单已收/状态
写入收款时间线
```

### 3.2 验证结果

```text
未选择账单 → 提示“请选择至少一笔账单”
选择两笔 → 合计 ¥1,800
确认后两笔状态变为已缴
超额输入 → 提示“收款金额必须大于 0 且不超过未收金额”
超额时账单未被修改
```
