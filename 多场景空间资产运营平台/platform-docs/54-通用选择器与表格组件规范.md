# 通用选择器与表格组件规范

> 状态：SearchSelect / TreeSelect 已实现；高频选择器已替换；批量页面待部署验证  
> 目标：先统一 4 个高频组件，再批量替换页面  
> 组件：SearchSelect、TreeSelect、RemoteSelect、DataTable

---

## 1. 为什么先做这 4 个

当前：

```text
91 个原生 select
55 个手写 table
131 个项目、148 个房屋、148 个人员
大量页面没有搜索和分页
```

如果先逐页补 CRUD，选择器和表格规范一变，页面还要重改。

所以顺序是：

```text
先组件规范
再替换高频页面
最后补 CRUD 和页面模板
```

---

## 2. 统一设计原则

```text
1. 组件只负责“选择”和“展示”，不内嵌业务请求
2. 业务请求由页面传入 fetch 函数
3. 组件支持受控模式 v-model
4. 支持键盘操作
5. 支持加载、空结果、错误、禁用
6. 支持清空和已选回显
7. 默认不引入第三方 UI 库
```

## 3. SearchSelect

### 3.1 用途

适合本地数据量不大、但需要快速过滤的单选/多选。

```text
项目
人员
房屋
合同
账单
```

### 3.2 Props

```ts
interface SearchSelectProps {
  modelValue: string | number | Array<string | number> | null
  options: Array<Record<string, any>>
  labelKey?: string          // 默认 label
  valueKey?: string          // 默认 value
  placeholder?: string
  multiple?: boolean
  clearable?: boolean
  disabled?: boolean
  filterable?: boolean       // 默认 true
  filterKeys?: string[]      // 默认 [labelKey]
  pageSize?: number          // 本地分页，默认 50
  noDataText?: string
}
```

### 3.3 Emits

```ts
modelValue
change
search
```

### 3.4 交互

```text
点击输入框展开
输入关键字即时过滤
上下键移动
Enter 选中
Esc 关闭
点击外部关闭
多选显示 tag，可单个移除
清空按钮
无结果文案
```

### 3.5 视觉

```text
高度 34px
圆角 6px
聚焦边框品牌色
下拉最大高度 280px
选中项浅蓝底 + 左侧勾
禁用态降低透明度
```

### 3.6 页面适配

| 页面 | 数据 | 适配方式 |
|---|---|---|
| 顶部项目 | projects | SearchSelect，本地过滤 |
| 申请-申请人 | persons | SearchSelect，支持姓名/编码/手机号 |
| 合同-房屋 | houses | SearchSelect，显示房屋编码/名称/房态 |
| 合同-承租人 | persons | SearchSelect |
| 账单-账单 | bills | SearchSelect，显示账单号/人员/金额 |
| 补贴-合同 | contracts | SearchSelect |

## 4. RemoteSelect

### 4.1 用途

数据量大、需要后端搜索或按条件远程加载。

```text
人员
房屋
合同
账单
```

### 4.2 Props

```ts
interface RemoteSelectProps {
  modelValue: string | number | null
  fetch: (params: {
    keyword: string
    page: number
    size: number
  }) => Promise<{
    items: Array<Record<string, any>>
    total: number
  }>
  labelKey?: string
  valueKey?: string
  placeholder?: string
  debounce?: number         // 默认 250ms
  minChars?: number         // 默认 1
  pageSize?: number         // 默认 20
  cache?: boolean           // 默认 true
  clearable?: boolean
  disabled?: boolean
}
```

### 4.3 交互

```text
输入 1 个字符后请求
250ms 防抖
加载中显示 spinner
无结果提示“没有匹配项”
已选项在关闭后保持显示
重新打开时优先显示已选项
请求竞态只保留最后一次结果
```

### 4.4 需要的后端参数

当前接口多数只支持按项目查询，建议补：

```text
GET /persons?keyword=&page=&size=
GET /projects/{id}/houses?keyword=&status=&page=&size=
GET /guarantee/contracts?projectId=&keyword=&page=&size=
GET /billing/bills?projectId=&keyword=&status=&page=&size=
```

第一阶段可以：

```text
接口不变
页面先取全量
RemoteSelect 前端过滤
```

第二阶段再改后端分页。

## 5. TreeSelect

### 5.1 用途

空间层级、组织层级。

```text
设备绑定空间
通行授权空间
空间上级
项目组织
```

### 5.2 Props

```ts
interface TreeSelectProps {
  modelValue: string | number | null
  nodes: Array<{
    id: string | number
    label: string
    parentId?: string | number | null
    disabled?: boolean
    children?: any[]
  }>
  checkable?: boolean
  multiple?: boolean
  defaultExpandAll?: boolean
  expandLevel?: number       // 默认 2
  placeholder?: string
  clearable?: boolean
  searchable?: boolean       // 默认 true
  showPath?: boolean         // 默认 true
}
```

### 5.3 交互

```text
树形展开/收起
搜索时保留匹配节点及父路径
选中后输入框显示“楼栋 / 单元 / 楼层 / 房屋”
支持清空
支持禁用节点
支持单选/多选
```

### 5.4 适配

当前空间接口返回扁平数组：

```text
id
parentId
spaceName
spaceType
levelNo
```

组件内部构建树：

```text
parentId 为空 → 根
parentId 匹配 → 子节点
```

### 5.5 页面适配

```text
设备绑定 → 绑定空间
通行授权 → 授权空间
空间管理 → 上级空间
项目/组织 → 所属组织
```
