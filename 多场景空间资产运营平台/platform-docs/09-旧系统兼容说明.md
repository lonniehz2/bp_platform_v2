# 旧系统兼容说明

## 1. 登录兼容

新平台已兼容旧保障房系统的 PBKDF2 密码格式：

```text
pbkdf2$迭代次数$base64(盐)$base64(哈希)
```

登录成功后自动升级为新平台 BCrypt 哈希。

已验证：

```text
admin / admin123       成功
acceptor / acc123      成功
viewer / view123       成功
```

## 2. 平台管理

平台管理仍使用旧系统：

```text
http://192.168.31.11:8080/platform-admin
```

新平台顶栏“平台管理”直接打开该入口。

当前定位：

```text
平台管理：旧平台
业务场景：新平台
```
