# 财务口径样例确认

> 目的：用一组可核算样例确认本期/期初/欠费/收缴率/回收率口径  
> 状态：样例已计算，待财务负责人确认  
> 说明：本文件中的“本期实收”按账单归属期统计，不按收款日期。

---

## 1. 样例数据

### 1.1 合同

```text
合同：BC202611001
月租金：1,200
月补贴：300
每月应付：900
```

### 1.2 本期账单

| 账单 | 账期 | 应付 | 已收 | 未收 | 状态 |
|---|---|---:|---:|---:|---|
| B1 | 2026-12 | 900 | 500 | 400 | 部分缴 |
| B2 | 2027-01 | 900 | 0 | 900 | 未缴 |

### 1.3 期初账单

| 账单 | 账期 | 应付 | 已收 | 未收 | 标识 |
|---|---|---:|---:|---:|---|
| O1 | 2026-10 | 8,600 | 1,000 | 7,600 | 期初 |

---

## 2. 初始口径计算

```text
本期应收 = 900 + 900 = 1,800
本期实收 = 500 + 0 = 500
本期收缴率 = 500 / 1,800 = 27.78%
当期欠费 = 1,800 - 500 = 1,300
期初欠费 = 8,600 - 1,000 = 7,600
总欠费 = 7,600 + 1,300 = 8,900
期初回收率 = 1,000 / 8,600 = 11.63%
```

---

## 3. 场景一：本期收款 700

收款分配：

```text
B1：400（结清）
B2：300（部分）
```

结果：

```text
本期应收 = 1,800
本期实收 = 1,200
本期收缴率 = 66.67%
当期欠费 = 600
期初欠费 = 7,600
总欠费 = 8,200
```

关键确认：

```text
部分收款按账单分配
B1 已结清
B2 剩余 600
```

---

## 4. 场景二：期初回款 2,000

结果：

```text
期初回收 = 1,000 + 2,000 = 3,000
期初欠费 = 8,600 - 3,000 = 5,600
期初回收率 = 3,000 / 8,600 = 34.88%
总欠费 = 5,600 + 600 = 6,200
```

关键确认：

```text
期初回款不计入本期实收
期初回收率单独计算
总欠费包含期初
```

---

## 5. 场景三：期初退款 500

结果：

```text
期初回收净额 = 3,000 - 500 = 2,500
期初欠费 = 8,600 - 2,500 = 6,100
期初回收率 = 2,500 / 8,600 = 29.07%
总欠费 = 6,100 + 600 = 6,700
```

关键确认：

```text
退款冲减期初回收
不冲减本期实收
退款按金额审批
必须关联原期初收款
```

## 6. 口径确认点

### 6.1 本期实收

```text
按账单归属期统计
不按收款日期统计
```

原因：

```text
本期收缴率反映本期账单回收情况
现金流可另设“本期收款金额”
```

### 6.2 期初欠费

```text
只统计 source_type=OPENING 的未收金额
不计入本期应收
不计入本期收缴率
```

### 6.3 总欠费

```text
总欠费 = 期初欠费 + 当期欠费
```

### 6.4 期初回收率

```text
期初回收率 = 期初回收净额 / 期初欠费基数
```

建议期初欠费基数使用：

```text
账期开始时点上的期初欠费
```

避免退款后分母变化导致指标跳动。

### 6.5 补贴/减免

```text
补贴减少应付
减免减少应付
两者都不等于实收
```
