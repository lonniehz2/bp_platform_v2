# 用户、角色、权限与数据范围重构方案

> 状态：设计稿，未编码  
> 目标：消除用户管理、角色管理、菜单管理的重复入口  
> 数据范围规则：角色默认范围取并集，用户例外只能收窄

---

## 1. 当前问题

侧边栏同时存在：

```text
用户与权限
  ├── 用户管理
  ├── 角色管理
  └── 权限清单

独立入口
  ├── 用户管理
  └── 菜单与角色
```

问题：

```text
用户管理重复
角色/菜单管理重复
页面标题重复
职责边界不清
权限和数据范围分散
```

---

只保留一个入口：

```text
系统与数据
  └── 用户与权限
        ├── 用户

        └── 权限清单
```

移除侧边栏：



### 用户

```text
用户列表

分配角色
设置数据范围例外
启用/停用
查看最终权限
```

### 角色

```text
角色列表
新增/编辑/软删除角色
分配菜单权限
分配动作权限
设置默认数据范围

```

### 权限清单

只读：

```text
菜单权限
动作权限
权限编码

```

不在权限清单里做角色分配。

---

## 4. 权限模型

```text
菜单权限：页面是否可见/可进入
动作权限：按钮和接口，如 user:create、contract:approve
数据范围：能看哪些项目/组织
```

角色绑定：

```text
角色 → 菜单权限 + 动作权限 + 默认数据范围
用户 → 角色 + 数据范围例外
```

最终权限：

```text
用户功能权限 = 所有角色功能权限的并集
用户数据范围 = 角色默认范围并集 ∩ 用户例外
```

---

## 5. 数据范围模型

### 5.1 范围类型

```text
ALL          全部项目
CURRENT      当前项目
PROJECTS     指定项目
ORGS         指定组织
SELF         仅本人
NONE         无数据
```

不要用“空集合”表示全部，必须显式使用 `ALL`。

### 5.2 角色默认范围

角色保存：

```text
dataScopeType
projectIds
orgIds
```

示例：

```text
角色：项目收费员
默认范围：CURRENT

角色：区域财务
默认范围：PROJECTS，项目 A、B、C

角色：稽核员
默认范围：ALL，只读
```

### 5.3 用户例外

用户保存：

```text
scopeOverrideEnabled
dataScopeType
projectIds
orgIds
```

规则：

```text
用户默认继承角色范围
只有需要例外时才开启覆盖
用户例外只能收窄，不能扩大
```

### 5.4 最终范围计算

```text
roleScope = union(所有角色的默认范围)
userScope = 用户例外范围（没有则为 null）
effectiveScope = userScope == null ? roleScope : roleScope ∩ userScope
```

示例：

```text
角色范围：项目 A、B、C
用户例外：项目 B、C
最终范围：项目 B、C
```

```text
角色范围：ALL
用户例外：项目 A
最终范围：项目 A
```

```text
角色范围：项目 A
用户例外：项目 B
最终范围：空，保存时应拒绝
```

### 5.5 校验

保存用户例外时：

```text
用户例外必须是角色范围的子集
不允许通过用户例外扩大角色范围
越界直接报错
```

服务端必须校验，不能只靠前端。

## 6. 多角色并集规则

```text
角色 1：项目 A
角色 2：项目 B
角色并集：项目 A、B
用户例外：项目 A
最终：项目 A
```

说明：

```text
并集用于功能权限和数据范围
用户例外只做收窄
```

风险控制：

```text
给用户分配多个宽范围角色时，前端提示最终范围
角色分配需要权限
ALL 范围角色只允许平台管理员分配
```

## 10. 迁移方案

### 第一步：导航去重

```text
删除 users、menus 侧边栏入口
保留 rbac
旧地址重定向
```

### 第二步：页面合并

```text
Users.vue → UserPanel
Menus.vue → RolePanel
新增 PermissionPanel
Rbac.vue 统一壳
```

### 第三步：角色默认范围

```text
新增角色数据范围字段和表
为现有角色设置默认范围
```

### 第四步：用户例外迁移

```text
现有 bp_user_project / bp_user_org 转为用户例外
未设置例外的用户继承角色
```

### 第五步：生效校验

```text
角色范围并集
用户例外收窄
服务端校验越界
```

### 第六步：回归

```text
admin
finance
auditor
asset clerk
```
