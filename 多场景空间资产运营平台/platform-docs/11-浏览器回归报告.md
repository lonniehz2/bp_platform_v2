## 3. 回归发现

### 计费项目 API 缺失

页面报错：

```text
feeItems is not a function
```

原因：

```text
api.js 缺少 feeItems/createFeeItem/toggleFeeItem
```

已修复。

### favicon 500

每个页面都出现：

```text
/favicon.ico 500
```

原因：

```text
静态资源不存在，被全局异常处理成 500
```

已增加 favicon，当前返回 200。

### 空数据页面

以下页面内容较短，属于正常空状态：

```text

```

页面没有 `.error`，接口没有 4xx/5xx。
