## 4. 第一迭代范围

第一迭代只做“三个重点 + 必要底座”，不铺开全部页面。

### 4.1 后端任务

#### BE-01 多账单收款

```text
新增 PaymentAllocationCmd
新增 payBatch / payWithAllocations
校验多账单属于同一合同
校验金额不超过各自未收
一条 payment 多条 allocation
统一生成收据
事务保证
```

涉及：

```text
BillingService
BillingController
bp_payment
bp_payment_allocation
bp_receipt
```

验收：

```text
选择两笔账单
第一笔全额、第二笔部分
合计正确
账单状态正确
收据一张
```

#### BE-02 驾驶舱账期指标

```text
按账期范围查询
区分期初/当期
本期应收/实收/收缴率
期初欠费/回收率
总欠费
下钻参数
```

验收：

```text
本月/本季切换
期初不计入本期
总欠费包含期初
```

#### BE-03 设备继承来源

```text
绑定树查询返回 sourceSpaceId/sourceSpaceName/sourcePath/inheritLevel
区分 DIRECT/INHERITED
一个设备只出现一次
```

验收：

```text
102 继承 1 层门禁
来源路径正确
点击来源可定位
```

## 8. 风险

```text
现有页面与新设计路由并存
权限体系改造影响现有功能
收款改造涉及资金，必须强校验
驾驶舱口径需要财务确认
设备继承查询可能影响性能
```

控制：

```text
新路由先灰度
旧接口保持兼容
收款改造必须有事务和幂等
指标用统一 SQL/服务
继承查询限制层级
```
