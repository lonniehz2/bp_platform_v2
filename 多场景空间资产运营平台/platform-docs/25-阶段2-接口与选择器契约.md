# 阶段 2：接口与选择器契约

> 阶段：2 / 6  
> 状态：设计稿  
> 依据：阶段 0 对象冻结、阶段 1 状态/动作/权限矩阵  
> 说明：本阶段定义目标接口契约和选择器契约，不绑定当前实现。

---

## 1. 阶段目标

```text
页面需要的每个动作都有接口承接
列表不拉全量
选择器可搜索、可层级、可分页
接口权限与状态矩阵一致
接口返回字段满足页面显示
```

---

## 2. 通用约定

### 2.1 基础路径

```text
/api/v1/platform/*     平台共享能力
/api/v1/guarantee/*    保障房场景能力
```

### 2.2 认证

```text
Authorization: Bearer {token}
X-Tenant-Id: {tenantId}
```

### 2.3 响应

```json
{
  "code": "BP00000",
  "message": "成功",
  "data": {},
  "timestamp": 0
}
```

### 2.4 分页

请求：

```text
page=1
size=20
keyword=
status=
projectId=
```

响应：

```json
{
  "list": [],
  "total": 0,
  "page": 1,
  "size": 20,
  "hasMore": false
}
```

### 2.5 金额与日期

```text
金额：字符串或两位小数，避免浮点误差
日期：yyyy-MM-dd
时间：yyyy-MM-dd HH:mm:ss
ID：字符串，避免精度丢失
```

### 2.6 权限

```text
每个接口必须声明权限
数据范围由后端强制
前端隐藏不等于权限
```

### 2.7 幂等

以下接口必须支持幂等键：

```text
提交申请
提交合同
收款
退款
冲正
批量生成账单
批量导入
```

请求头：

```text
Idempotency-Key
```

### 2.8 错误码

```text
BP00000 成功
BP40001 参数错误
BP40301 无权限
BP40401 不存在
BP40901 状态冲突
BP40902 重复提交
BP42201 业务校验失败
BP50001 系统错误
```

## 8. 选择器契约

### 8.1 通用返回

```json

  "list": [

      "id": "1",
      "label": "A栋1单元101",
      "code": "HS-...",
      "status": "VACANT",
      "path": "A栋/1单元/1层/101",
      "selectable": true
    }
  ],
  "total": 1,
  "hasMore": false

```

### 8.2 选择器分级

```text
≤ 20 条：本地搜索下拉
```
