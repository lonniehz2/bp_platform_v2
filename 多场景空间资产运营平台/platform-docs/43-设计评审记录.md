## 3. 评审决策

### D01 财务口径签字

结论：确认。

确认口径：

```text
本期应收 = 账期范围内非期初账单应付合计
本期实收 = 这些账单已核销金额
本期收缴率 = 本期实收 / 本期应收
期初欠费 = 期初账单未收金额
总欠费 = 期初欠费 + 当期欠费
期初回收率 = 期初回收净额 / 期初欠费基数
```
