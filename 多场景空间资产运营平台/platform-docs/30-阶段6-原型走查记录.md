## 4. 走查发现

### ISSUE-001：合同详情直接收款缺少账单选择

严重级别：中

现象：

```text
合同详情点击“直接收款”直接打开金额弹窗
没有先选择未结清账单
```

设计修正：

```text
合同详情直接收款必须先选择未结清账单
或默认最近一期未结清账单并提示
收款仍调用账单收费统一接口
```

### ISSUE-002：申请转轮候动作在所有角色可见

严重级别：中

现象：

```text
原型中“转轮候”按钮不按角色隐藏
设计矩阵要求 application:waitlist 权限
```

设计修正：

```text
转轮候只对窗口受理/项目管理员/场景管理员显示
审核员不显示
```

### ISSUE-003：设备继承页签只显示数量

严重级别：中

现象：

```text
原型显示“继承 1”
未显示继承来源空间
```

设计修正：

```text
继承设备列表显示来源空间和路径
区分直绑/继承
```

### ISSUE-004：驾驶舱缺少时间范围

严重级别：低

现象：

```text
原型只有项目切换和刷新
```

设计修正：

```text
增加时间范围
KPI/图表随范围变化
期初/当期分开
```

### ISSUE-005：列表页签为静态

严重级别：低

现象：

```text
申请、账单页签在原型中不切换内容
```

设计修正：

```text
正式页面必须按页签查询
待审核、草稿、已通过分别查询
```
