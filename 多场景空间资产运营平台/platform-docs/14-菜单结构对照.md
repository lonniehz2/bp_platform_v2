## 新系统分组

已按原系统调整：

```text
工作台
├─ 运营驾驶舱
├─ 统一查询
└─ 消息中心

风险与预警
├─ 风险告警
├─ 欠费清单
└─ 信用惩戒

保障服务
├─ 人员档案
├─ 申请受理
├─ 年审复核
└─ 公示管理

合同与房源
├─ 房源与空间
├─ 合同台账
├─ 合同变更
├─ 日房态
└─ 短租订单

收费与账务
├─ 账单与缴费
├─ 计费项目
├─ 押金与补贴
├─ 资金流水
├─ 抄表管理
├─ 能耗分析
└─ 报表导出

通行与设备
├─ 设备管理
└─ 访客通行

服务与监督
├─ 工单维保
└─ 投诉与申诉

系统与数据
├─ 用户管理
├─ 菜单与角色
├─ 开放平台
├─ 监管报送
├─ 审批中心
├─ 迁移异常
└─ 使用帮助
```
