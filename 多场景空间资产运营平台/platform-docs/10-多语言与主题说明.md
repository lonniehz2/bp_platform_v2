# 多语言与主题说明

## 1. 当前实现

### 显式 i18n

```text
登录页
侧边栏菜单
页面标题
```

使用 `vue-i18n`，支持：

```text
zh-CN
en-US
```

语言参数：

```text
http://192.168.31.11:8090/?lang=en
```

### 页面静态文案

业务页面仍保留了中文模板，增加了过渡层：

```text
复用旧保障房系统的 zh-CN / en-US 词条
按中文文本精确匹配翻译
MutationObserver 处理动态渲染
```

只翻译 UI 文案，不翻译：

```text
人员姓名
项目名称
房屋名称
合同编号
金额
编码
```

因此业务数据仍保持原样，界面标签可以中英切换。

## 2. 深色/浅色

```text
浅色：默认
深色：html.dark
```

切换入口：

```text
顶栏月亮/太阳按钮
登录页右上角
```
