## 2. 走查方式

```text
低保真原型

验收用例评审
```

## 4. 走查场景

### 场景 1：申请到轮候

角色：窗口受理 → 审核员

步骤：

```text
新增申请
暂存
刷新恢复
提交
审核通过
转轮候
```

验证：

```text
草稿可恢复
提交后不可编辑
审核意见必填
状态正确
轮候记录生成
```

### 场景 2：申请退回与重提

角色：审核员 → 窗口受理

步骤：

```text
退回补充
窗口修改
重新提交
审核通过
```

验证：

```text
退回意见可见
可编辑
重新提交不重复生成申请
历史记录保留
```

### 场景 3：配租冲突

角色：项目管理员

步骤：

```text
两个轮候对象同时选择同一房源
一个成功
另一个提示冲突
```

验证：

```text
房源只能配租一次
冲突提示明确
失败方状态不变
```

### 场景 4：合同模板审批

角色：窗口受理 → 审核员

步骤：

```text
创建合同
提交审批
审批通过
合同生效
```

验证：

```text
合同状态正确
审批记录可见
房源状态联动
账单可生成
```

### 场景 5：合同无模板直通

角色：项目负责人

步骤：

```text
创建合同
无模板
直接生效
填写说明
```

验证：

```text
有权限角色可操作
普通经办人不可见
日志记录
时间线显示“无审批直接生效”
```

### 场景 6：账单批量生成与收款

角色：财务

步骤：

```text
选择合同
批量生成
生成结果
单笔收款
打印收据
```

验证：

```text
重复账单被拒绝
金额正确
收款后状态更新
收据可打印
```

### 场景 7：账单减免审批

角色：项目管理员 → 场景财务

步骤：

```text
发起减免
审批通过
应付减少
```

验证：

```text
阈值触发审批
审批意见必填
金额正确
日志完整
```

### 场景 8：期初欠费回款

角色：财务

步骤：

```text
查看期初欠费
登记回款
查看期初回收率
```

验证：

```text
不计入当期收缴率
单独统计
冲正/退款关联原收款
```

### 场景 9：设备绑定与导入

角色：设备运维

步骤：

```text
选择空间
绑定设备
查看继承
解绑
导入 CSV
查看失败行
```

验证：

```text
一个设备一个空间
继承正确
MAC 唯一
导入结果正确
```

### 场景 10：财务跨组织权限

角色：财务

步骤：

```text
登录
查看账单
尝试查看平级组织
尝试导出
```

验证：

```text
只能看本级及下级
平级组织不可见
导出受控
```

## 5. 页面体验检查

### 5.1 可发现性

```text
菜单名称能看懂
主要动作在首屏
筛选不隐藏过深
详情入口明显
```

### 5.2 可完成性

```text
从列表到完成一次业务不超过 3 次关键点击
选择器可搜索
层级可选
错误提示具体
提交有反馈
```

### 5.3 可恢复性

```text
草稿可恢复
失败可重试
返回不丢筛选
刷新不丢上下文
```

### 5.4 显示

```text
无裸 ID
状态中文
金额格式统一
空值显示“-”
无权限有提示
```

## 8. 验收用例格式

```text

场景
前置条件
角色
步骤
预期结果
实际结果
问题编号
状态
```

示例：

```text
AC-APP-001
场景：申请提交
前置：窗口登录，本项目有人员
步骤：新增申请 → 暂存 → 刷新 → 恢复 → 提交
预期：草稿恢复；提交后状态 SUBMITTED；不可编辑
```
