## 3. 主流程

### 步骤 1：申请登记

角色：

```text
窗口受理
```

页面：

```text
/guarantee/applications
```

动作：

```text
新增申请
填写申请人
填写家庭信息
填写保障类型
暂存
提交
```

状态：

```text
空 → DRAFT → SUBMITTED
```

接口：

```text
POST /guarantee/applications
PUT /guarantee/applications/{id}
POST /guarantee/applications/{id}/submit
```

验证：

```text
草稿自动保存
刷新后恢复
必填校验
提交后不可编辑
```

### 步骤 2：资格审核

角色：

```text
审核员
```

页面：

```text
/guarantee/applications/review
```

动作：

```text
查看材料
填写意见
通过
```

状态：

```text
SUBMITTED → REVIEWING → APPROVED
```

接口：

```text
GET /guarantee/applications/review-tasks
POST /guarantee/applications/{id}/approve
```

验证：

```text
任务只出现在授权审核员
意见必填
审批记录可见
```

### 步骤 3：进入轮候

角色：

```text
窗口受理 / 项目管理员
```

页面：

```text
/guarantee/applications → 申请详情
```

动作：

```text
转轮候
```

状态：

```text
APPROVED → WAITLISTED
```

接口：

```text
POST /guarantee/applications/{id}/waitlist
```

验证：

```text
重复转轮候被拒绝
轮候队列生成排队号
```

### 步骤 4：配租

角色：

```text
项目管理员
```

页面：

```text
/guarantee/allocation
```

动作：

```text
选择轮候对象
选择空置房源
确认配租
```

状态：

```text
WAITLISTED → ALLOCATED
房源 VACANT → ALLOCATED
```

接口：

```text
GET /guarantee/waitlist
GET /guarantee/houses/options?houseStatus=VACANT
POST /guarantee/allocation
```

验证：

```text
只能选空置房源
房源被并发配租时提示冲突
配租后房源不可再选
```

### 步骤 5：合同签约

角色：

```text
窗口受理 / 项目管理员
```

页面：

```text
合同详情 / 合同签约向导
```

动作：

```text
创建合同草稿
确认承租人
确认房屋
确认租金、押金、账期
提交
审批
生效
```

状态：

```text
DRAFT → APPROVING → ACTIVE
```

接口：

```text
POST /guarantee/contracts
POST /guarantee/contracts/{id}/submit
POST /platform/approvals/tasks/{id}/approve
```

验证：

```text
合同编号按年月生成
房屋、承租人必选
起止日期校验
账单周期/账单日保存
```

### 步骤 6：无模板直通变体

条件：

```text
未绑定合同审批模板
操作人有 contract:effective:no_approval
```

动作：

```text
确认无模板
填写说明
直接生效
```

状态：

```text
DRAFT → ACTIVE
```

验证：

```text
生成 CONTRACT_EFFECTIVE_WITHOUT_APPROVAL 日志
合同时间线显示“无审批直接生效”
普通经办人无此权限
```

### 步骤 7：入住办理

角色：

```text
项目管理员 / 设备运维
```

页面：

```text
/guarantee/occupancy
```

动作：

```text
验房
交钥匙
设备授权
确认入住
```

状态：

```text
合同 ACTIVE
房源 ALLOCATED → OCCUPIED
```

接口：

```text
POST /guarantee/occupancy
POST /guarantee/access-grants
```

验证：

```text
入住后房源状态更新
设备授权可撤销
入住记录可追溯
```

### 步骤 8：生成账单

角色：

```text
财务
```

页面：

```text
/guarantee/billing
```

动作：

```text
选择合同
选择账期
生成账单
```

数据：

```text
账单金额 1200
补贴 300
应付 900
```

状态：

```text
DRAFT → ISSUED
```

接口：

```text
POST /guarantee/billing/bills
POST /guarantee/billing/bills/batch-generate
```

验证：

```text
补贴正确抵扣
应付金额正确
账单编号按年月
重复生成被拒绝
```

### 步骤 9：收款

角色：

```text
财务
```

页面：

```text
/guarantee/billing
```

动作：

```text
登记收款
选择收款方式
确认收款
打印收据
```

状态：

```text
ISSUED → PAID
```

接口：

```text
POST /guarantee/billing/bills/{id}/pay
GET /guarantee/billing/receipts/{paymentId}
```

验证：

```text
正常收款不审批
收款生成收据
账单余额更新
重复提交幂等
```

### 步骤 10：退租

角色：

```text
项目管理员 / 财务
```

页面：

```text
/guarantee/terminations
```

动作：

```text
发起退租
验房
结算
押金退还
释放房源
```

状态：

```text
ACTIVE → TERMINATING → TERMINATED
房源 OCCUPIED → VACANT
```

接口：

```text
POST /guarantee/contracts/{id}/terminate
POST /guarantee/contracts/{id}/settle
POST /guarantee/contracts/{id}/complete-termination
```

验证：

```text
退租前有未结账单时提示
押金退还按金额审批
退租后房源可重新配租
```

## 4. 异常分支

### 4.1 申请退回

```text
REVIEWING → RETURNED
窗口补充材料
RETURNED → SUBMITTED
```

验证：

```text
退回意见必填
申请人可编辑
重新提交不重复生成申请
```

### 4.2 申请驳回

```text
REVIEWING → REJECTED
```

验证：

```text
驳回意见必填
不能转轮候
可新建申请
```

### 4.3 配租取消

```text
ALLOCATED → WAITLISTED
房源 ALLOCATED → VACANT
```

验证：

```text
释放房源
保留配租记录
记录操作人
```

### 4.4 账单减免

```text
ISSUED → 减免审批 → ISSUED/WAIVED
```

验证：

```text
金额阈值触发审批
审批通过后应付减少
审批记录可追溯
```

### 4.5 收款冲正/退款

```text
PAID → 冲正/退款审批 → PAID/REFUNDED
```

验证：

```text
必须关联原收款
金额不能超过原收款
按阈值审批
收据状态更新
```

### 4.6 期初欠费回款

```text
期初账单 → 期初回款
```

验证：

```text
不计入当期收缴率
单独统计期初回收
冲正/退款关联原期初收款
```

→ 轮候
→ 配租
→ 合同详情
→ 入住
→ 账单

要求：

```text
每一步能返回上一级
每一步保留项目上下文
详情页不丢失筛选条件
操作完成回到合理位置
```

## 6. 权限验证

| 步骤 | 角色 | 允许 | 禁止 |
|---|---|---|---|
| 申请登记 | 窗口 | 本项目 | 其他项目 |
| 审核 | 审核员 | 授权项目 | 未授权项目 |
| 配租 | 项目管理员 | 本项目 | 跨项目房源 |
| 签约 | 窗口/项目管理员 | 本项目 | 跨项目合同 |
| 收款 | 财务 | 授权组织树 | 平级/上级组织 |
| 退租 | 项目管理员 | 本项目 | 跨项目 |
| 驾驶舱 | 领导 | 授权项目 | 全租户默认 |

配租状态与房源状态一致
合同生效与房源占用一致
账单金额与合同租金一致
收款金额与账单余额一致
退租完成与房源释放一致
审批记录与业务状态一致

## 9. 纵切发现的问题

需要后续确认：

```text
1. 申请转轮候后，申请详情是否还能编辑
2. 配租取消是否允许在原房源释放前重新配租
3. 合同无模板直通是否允许财务角色
4. 入住办理是否必须生成设备授权
5. 退租时未结账单是否允许完成退租
6. 期初欠费是否允许在当期账单页面直接回收
7. 房源 OCCUPIED 状态由合同还是入住触发
```
