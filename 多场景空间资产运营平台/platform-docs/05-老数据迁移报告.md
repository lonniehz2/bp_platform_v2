## 2. 账单异常

4 条老账单因新库唯一约束未迁入：

```text
tenant_id + contract_id + period_start + period_end
```

冲突合同：

```text
contract_id = 376763825598369792
```

未迁入账单：

```text
FB376763887191724032   2026-09-07 ~ 2026-10-07
FB376764175394934784   2026-09-07 ~ 2026-10-07
FB376765303348137984   2026-10-31 ~ 2026-11-06
FB376766074462539776   2026-09-07 ~ 2026-10-07
```

原因：

```text
老库同一合同、同一周期存在多张账单
新库 bp_bill 唯一索引 uk_bp_bill_contract_period 不允许重复
```

处理建议：

```text
不要直接删除
先由财务确认是重复出账、补录还是历史调整
合并或补一张调整单
再决定是否迁入
```

当前迁移策略是“保留第一张，跳过重复”，避免静默覆盖。
