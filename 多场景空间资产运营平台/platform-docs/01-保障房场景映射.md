# 保障房场景映射（第一场景）

> 目标：保障房作为平台第一个场景验证，不整体重写老系统  
> 场景码：`GUARANTEE`

---

## 1. 场景定义

```text
scene_code = GUARANTEE
business_mode:
  PUBLIC_RENTAL       公租房
  AFFORDABLE_RENTAL   保租房
  TALENT_APARTMENT    人才公寓
  DORMITORY           宿舍
  OTHER               其他
```

---

## 2. 空间模板

基础：

```text
小区 → 楼栋 → 单元 → 楼层 → 房屋
```

可选子级：

```text
房屋 → 床位
房屋 → 内房 → 床位
```

`sub_unit_mode`：

```text
NONE
BED
INNER_ROOM
INNER_ROOM_BED
```

规则：

```text
未分割房屋：房屋是房源
分割为内房：内房是房源
宿舍/青旅：床位是房源
同一房屋不能同时作为房源又挂子房源
```

