## 2. 核心模型

```text
House 1 → N RentableUnit
RentableUnit 1 → N HouseFeature
RentableUnit 1 → N HouseMedia
RentableUnit 1 → N HouseListing
HouseListing 1 → N ListingChannel
HouseListing 1 → N PricePlan
HouseListing 1 → N Availability
Booking N → 1 RentableUnit
Booking 1 → 0..1 Order
Order 1 → 0..1 Contract
```

### 2.1 对象职责

| 对象 | 职责 |
|---|---|
| House | 物理房源资产 |
| RentableUnit | 可独立出租的整套/房间/床位 |
| HouseFeature | 房间内部配置 |
| HouseMedia | 图片、视频、户型图、VR |
| HouseListing | 对外发布的房源商品 |
| ListingChannel | 渠道发布关系 |
| PricePlan | 价格计划 |
| Availability | 可租日历 |
| Booking | 看房预约 |
| Order | 市场化订单 |


