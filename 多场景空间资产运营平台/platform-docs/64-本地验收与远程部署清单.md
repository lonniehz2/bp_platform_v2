```powershell

cd platform-local
```

## 三、远程 SQL 顺序

远程基线为 `01e9635`，本批需要执行：

```text
platform-sql/020_role_action.sql

platform-sql/022_backfill_role_actions.sql
```

要求：

```text
先备份数据库
按顺序执行

确认 bp_role_action 和 bp_role_action_menu 行数
确认已有角色 backfill 完成
```

校验 SQL：

```sql
select count(*) from bp_role_action;
select count(*) from bp_role_action_menu;
select count(*) from bp_menu where menu_type='PAGE';
```
