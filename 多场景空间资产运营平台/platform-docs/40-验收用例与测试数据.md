## 2. 申请用例

### AC-APP-001 新增草稿

```text
角色：窗口受理
步骤：申请受理 → 新增申请 → 填写申请人/家庭 → 暂存
预期：生成 DRAFT；列表可见；刷新可恢复
```

### AC-APP-002 提交校验

```text
角色：窗口受理
步骤：草稿缺少联系电话 → 提交
预期：字段校验提示；状态仍为 DRAFT
```

### AC-APP-003 审核通过

```text
角色：审核员
步骤：待审核 → 查看 → 填写意见 → 通过
预期：状态 APPROVED；审批记录生成
```

### AC-APP-004 驳回

```text
角色：审核员
步骤：填写驳回意见 → 驳回
预期：状态 REJECTED；不能转轮候；可新建申请
```

### AC-APP-005 退回重提

```text
角色：审核员 → 窗口
步骤：退回补充 → 窗口修改 → 重新提交
预期：状态 RETURNED → SUBMITTED；不重复生成申请
```

### AC-APP-006 转轮候

```text
角色：窗口/项目负责人/场景管理员
步骤：申请详情 → 转轮候
预期：状态 WAITLISTED；生成轮候记录；审核员不可见按钮
```
