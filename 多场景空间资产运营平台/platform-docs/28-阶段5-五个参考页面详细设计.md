# P1 运营驾驶舱

## 1.1 路由与角色

```text
/guarantee/workbench
```

可见角色：

```text
场景管理员
项目管理员
领导
财务（授权范围）
设备运维（设备部分）
```

## 1.2 布局

```text
顶部上下文
├─ 项目选择
├─ 时间范围（含期初/当期口径）
└─ 刷新

KPI 区
├─ 房源总数/空置/已配租/已入住
├─ 申请数/待审数
├─ 生效合同
├─ 应收/已收/欠费
├─ 收缴率
└─ 设备/告警/待办

图表区
├─ 房源结构
├─ 账单趋势
├─ 收缴率趋势
└─ 设备类型/状态

任务区
├─ 待审批
├─ 逾期账单
├─ 未处理告警
└─ 年审到期

最近业务
├─ 最近合同
├─ 最近收款
└─ 最近事件
```

## 1.3 字段与口径

```text
房源总数
空置
已配租
已入住
申请数
待审数
生效合同
应收
已收
当期欠费
期初欠费
总欠费
当期收缴率
设备数
在线设备
待处理告警
待办数
```

口径：

```text
本期应收 = 账期范围内非期初账单应付合计
本期实收 = 这些账单已核销金额
本期收缴率 = 本期实收 / 本期应收
当期欠费 = 本期应收 - 本期实收
期初欠费 = 期初账单未收金额
总欠费 = 期初欠费 + 当期欠费
期初回收率 = 期初回收 / 期初欠费
```

时间维度：

```text
按账期筛选
本月 / 本季 / 本年 / 自定义
默认本月
```

## 1.4 交互

```text
KPI 点击下钻
图表点击下钻
待办直达
告警直达
项目/时间影响全页
```

## 1.5 权限

```text
guarantee:dashboard:view
```

财务指标按财务数据范围。

## 1.6 接口

```text
GET /guarantee/dashboard/summary
GET /guarantee/dashboard/charts
GET /guarantee/dashboard/todos
GET /guarantee/dashboard/alerts
GET /guarantee/dashboard/recent
GET /guarantee/dashboard/drill
```

## 1.7 验收

```text
指标可解释
下钻不丢失筛选
期初/当期分开
无权限不泄露数据
```

# 6. 页面统一规则

```text
所有页面支持项目上下文
所有列表服务端分页
所有选择器不拉全量
所有详情有状态和动作
所有动作有权限
所有关键动作有审计
不显示裸 ID
状态中文
金额两位小数
空值显示“-”
```
