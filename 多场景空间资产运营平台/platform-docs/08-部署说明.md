## 3. 打包

前端：

```powershell
cd platform-frontend
node node_modules\vite\bin\vite.js build
```

复制到后端静态目录：

```powershell
cd ..
Remove-Item platform-backend\src\main\resources\static -Recurse -Force -ErrorAction SilentlyContinue
New-Item -ItemType Directory platform-backend\src\main\resources\static | Out-Null
Copy-Item platform-frontend\dist\* platform-backend\src\main\resources\static -Recurse
```

后端：

```powershell
cd platform-backend
$env:JAVA_HOME='D:\Work\tools\jdk-17.0.20.1+1'
D:\Work\tools\apache-maven-3.9.9\bin\mvn.cmd -B -q -DskipTests package -s D:\Work\tools\m2-settings.xml
```

## 4. 上传并启动

```bash
# 服务器上
mkdir -p /home/luo/bp-platform-new
cd /home/luo/bp-platform-new
# 上传 target/multi-scene-platform.jar
nohup env DB_PASSWORD='******' SERVER_PORT=8090 \
  java -Xms512m -Xmx1024m -XX:+UseG1GC -Dfile.encoding=UTF-8 \
  -jar multi-scene-platform.jar > app.log 2>&1 &
```

## 6. 更新流程

```text
改代码
→ 前端 build
→ copy dist 到 backend static
→ mvn package
→ 上传 jar
→ 停旧进程
→ 启动新进程
→ health + 页面 + 登录验证
```

停止：

```bash
pkill -f 'multi-scene-platform.jar'
```

注意：不要执行包含当前命令自身的 `pkill` 模式，避免误杀 shell。

## 7. 回滚

```text
保留上一个 multi-scene-platform.jar
停新进程
恢复旧 jar
启动
验证 health
```

旧保障房系统 8080 不受影响。
