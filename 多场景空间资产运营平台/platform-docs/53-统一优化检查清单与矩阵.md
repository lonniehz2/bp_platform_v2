# 统一优化检查清单与矩阵

> 目的：把“逐页改”变成“按统一规范批量改”  
> 范围：54 个 Vue 页面、48 个 `/guarantee/*` 路由  
> 状态：检查清单，未编码

---

## 1. 代码现状盘点

```text
页面文件：54
路由：48
select：91
table：55
button：146
form field：282
modal 遮罩：8
空状态：77
错误提示：53
日期输入：32
内联 style：202
共享组件：只有 Pager.vue
```

结论：

```text
页面是“每页各写一套”
不是“组件 + 模板 + token”体系
```

## 5. 交互与反馈检查

| 检查项 | 现状 | 建议 |
|---|---|---|
| 提交按钮 busy 禁用 | 部分有，部分没有 | 统一 `:disabled="busy"` |
| 删除/作废二次确认 | 部分有，部分没有 | 统一 ConfirmDialog |
| 接口失败提示 | 每页 `.error` | 全局错误映射 |
| 空数据 | 77 处手写 | EmptyState |
| 加载状态 | 大部分无 skeleton | DataTable loading |
| 刷新后保持筛选 | 多数丢失 | URL query 持久化 |
| 离开未保存提示 | 无 | 表单 dirty guard |
| 重复提交 | 有风险 | 请求锁 + 幂等键 |

## 9. 结论

```text
当前页面能完成流程
但组件复用、CRUD 完整性、搜索选择器、表格交互都不成体系
统一优化应先做组件和模板，再逐页替换
```
