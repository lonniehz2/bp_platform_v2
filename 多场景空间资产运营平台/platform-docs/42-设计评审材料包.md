## 6. 评审重点

### 6.1 合同直接收款

```text
是否必须先选账单
是否允许一笔或多笔
是否允许部分收款
是否必须生成分配明细
无账单是否禁用
```

### 6.2 申请转轮候

```text
角色是否只有窗口/项目负责人/场景管理员
审核员是否完全不可见
条件是否为 APPROVED
```

### 6.3 设备继承来源

```text
是否展示来源空间和路径
是否支持点击跳转
是否显示继承层级
一个设备是否只绑定一个空间
```

### 6.4 财务口径

```text
本期实收是否按账单归属期
期初欠费是否不计入本期
总欠费是否包含期初
期初回收率分母是否明确
```

### 6.5 权限

```text
财务组织树
项目管理员跨项目人员
根组织财务授权
字段脱敏
导出
```

### 6.6 接口缺口

```text
配租创建/取消
合同审批撤回
合同设备授权
设备报修/启用
账单关闭
```

## 10. 残余风险

```text
没有真人可用性测试
术语和操作习惯未经过真实用户验证
首次使用学习成本未知
```

建议：

```text
评审记录中明确接受
上线前小范围试点/UAT
试点后修正术语和操作路径
```
