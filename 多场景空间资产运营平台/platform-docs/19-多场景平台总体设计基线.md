# 多场景平台总体设计基线

> 状态：设计基线 v1.0  
> 日期：2026-11-09  
> 适用范围：平台基础能力、保障房场景、IoT 基础能力  
> 后续范围：物业、资产经营等场景应用逐步扩展  
> 说明：本文档在“合同详情、账单收费、设备绑定”三个标准页面详细设计之前，先冻结全局设计基线。

## 0. 已确认决策

| 编号 | 决策 |

## 1. 目标与原则

### 1.1 总目标

建设一个支持多场景、多租户、统一权限、统一审批、统一设备能力的空间资产运营平台。

### 1.2 五项核心目标

```text
多场景平台
新前端
业务闭环
UI 操作友好简单
显示内容全面
```

### 1.3 设计原则

```text
平台能力下沉，场景能力上浮
共享对象统一，场景字段隔离
流程可配置，但不牺牲资金安全
权限后端强制，不依赖前端隐藏
编码展示友好，不显示裸 ID
业务对象有状态、有动作、有日志
页面可复用，不为单页重复造轮子
```

## 4. 多租户与权限

### 4.1 权限模型

```text
RBAC + 数据范围 + 字段权限
```

### 4.2 数据范围

```text
PLATFORM      平台级，仅平台管理员，跨租户分次查询
TENANT        本租户
ORG_TREE      本级组织 + 下级组织 + 下级项目
PROJECT       当前项目
PROJECT_SET   指定项目集合
SELF          本人
CUSTOM        自定义
```

### 4.3 财务权限

```text
财务默认范围：ORG_TREE
范围 = 本级组织 + 下级组织 + 下级组织所属项目
```

规则：

```text
不默认看全租户
不默认看平级组织
不默认看上级组织
财务挂租户根组织 → 可看全租户，但必须有显式授权
根组织财务授权需审批和审计
授权有有效期，到期自动收回
```

### 4.4 项目管理员权限

```text
项目管理员默认只能看本项目
只能看与本项目有关联的人员
不能全局搜索人员
不能查看其他项目人员档案
显式授权后才可跨项目
```

人员可见条件：

```text
人员与当前项目存在关系
或存在人员显式授权
```

### 4.5 字段权限

```text
身份证
手机号
住址
合同金额
银行账号
```

规则：

```text
字段权限取交集
显式拒绝优先
默认拒绝
导出同样受控
```

### 4.6 强制范围

以下全部执行数据范围过滤：

```text
列表
详情
导出
搜索
选择器
报表
驾驶舱
审批
```

不能只在前端过滤，后端必须校验。

## 5. 主数据与编码

### 5.1 编码原则

```text
内部 ID 与业务编码分离
内部 ID 用雪花 ID
业务编码用于展示、检索、打印
业务编码不可变
作废不复用
序列按租户/项目/期间独立
并发安全
```

### 5.2 编码规则

| 对象 | 编码规则 | 含年月 |
|---|---|---|
| 项目 | `PRJ-{地区码}-{4位序号}` | 否 |
| 空间 | `SP-{项目编码}-{6位序号}` | 否 |
| 房源 | `HS-{项目编码}-{6位序号}` | 否 |
| 合同 | `HT-{项目编码}-{YYYYMM}-{4位序号}` | 是 |
| 账单 | `BL-{项目编码}-{YYYYMM}-{5位序号}` | 是 |
| 收款 | `PY-{项目编码}-{YYYYMM}-{5位序号}` | 是 |
| 收据 | `RC-{项目编码}-{YYYYMM}-{5位序号}` | 是 |
| 设备 | `DV-{项目编码}-{类型}-{5位序号}` | 否 |
| 工单 | `WO-{项目编码}-{YYYYMM}-{5位序号}` | 是 |
| 审批 | `AP-{YYYYMMDD}-{6位序号}` | 是 |

### 5.3 五级地址

数据源：

```text
https://github.com/657258535/China-Area-Region-Administrative-Divisions
```

更新方式：

```text
平台管理员/运维管理员手动更新
每年至少一次
或行政区划调整公告后更新
不在运行时自动联网
```

更新流程：

```text
下载 province.json 和省份 JSON
→ 导入临时表
→ 校验编码/层级/父子关系
→ 查看变更
→ 发布新版本
→ 记录来源、校验值、操作人
```

### 5.4 地址强制

```text
中文项目 = country=CN 且 locale=zh-CN
中文项目强制省/市/区县/街道/社区五级地址
```

回退：

```text
第五级数据缺失时允许回退
需要 project:region:fallback 权限
不需要审批
必须记录原因和缺失层级
项目标记“地址待完善”
```

### 5.5 编码不可变性

```text
项目编码生成后不因地址修改而重算
已作废编码不复用
已撤销区划不物理删除
历史项目保留旧名称
```

## 6. 审批与流程

### 6.1 审批能力

```text
单级审批
多级审批
顺序审批
平行审批
多人会签 and
多人或签 or
抄送
办理
条件分支
转办
加签
撤回
退回补充
超时提醒
超时自动通过
超时升级
```

### 6.2 模板层级

```text
平台模板
  ↓ PATCH
场景模板
  ↓ PATCH
项目模板
```

默认：

```text
PATCH 继承
允许 NONE
```

### 6.3 PATCH 规则

允许：

```text
增加节点
修改节点名称
修改审批人
修改审批模式
增加条件
增加抄送
```

禁止：

```text
删除平台强制节点
降低平台强制审批要求
绕过金额审批
```

### 6.4 模板解析

```text
项目模板 → 场景模板 → 平台模板
```

同层级按条件匹配：

```text
业务类型
金额
合同类型
项目类型
组织范围
```

### 6.5 模板版本

```text
模板发布后版本不可改
审批实例固定使用发起时版本
上级更新不自动影响下级
下级提示“可升级”
升级需重新发布
```

### 6.6 合同类审批

合同类：

```text
签订
续签
变更
租金变更
期限变更
换房
退租
终止
```

规则：

```text
绑定模板 → 走审批
未绑定模板 → 可直接生效
```

无模板直通限制：

```text
仅授权角色可操作
普通经办人不能直接生效
必须有操作日志
日志类型：CONTRACT_*_WITHOUT_APPROVAL
合同详情时间线显示“无审批直接生效”
```

### 6.7 金额类审批

必须审批：

```text
账单调整
账单减免
退款
收款冲正
押金退还
补贴抵扣
发票红冲
```

规则：

```text
无模板也强制审批
正常收款不审批
```

默认阈值：

```text
< 100        项目负责人
100–5000     项目负责人 + 场景财务
≥ 5000       项目负责人 + 场景财务 + 平台财务
```

阈值可配置：

```text
平台默认
场景可覆盖
项目可在允许范围覆盖
版本化
生效时间
```

### 6.8 审批状态与业务状态

```text
业务状态：草稿/生效/变更中/退租中/已终止
审批状态：未提交/审批中/已通过/已驳回/已撤回
```

两者分离，不能混用。

## 7. 财务与账务

### 7.1 金额字段

```text
账单金额 amount
补贴金额 subsidy_amount
减免金额 waiver_amount
调整金额 adjustment_amount
应付金额 payable_amount
已核销金额 paid_amount
未收金额 outstanding_amount
期初金额 opening_amount
```

### 7.2 公式

```text
应付 = 账单金额 - 补贴 - 减免 - 调整
欠费 = 应付 - 已核销
当期收缴率 = 当期实收 / 当期应收
总欠费 = 期初欠费 + 当期欠费
期初欠费回收率 = 期初回收 / 期初欠费
```

### 7.3 账单状态

```text
DRAFT
ISSUED
PARTIAL
PAID
OVERDUE
WAIVED
CLOSED
```

### 7.4 财务动作

```text
账单生成
账单调整
减免
补贴抵扣
收款
部分收款
收款冲正
退款
开票
收据
催缴
对账
```

规则：

```text
金额两位小数
不允许物理删除
冲正代替删除
减免/退款走审批
合同详情直接收款复用账单收费服务
收款必须能分配到账单
未分配收款单独管理
押金作为负债单独核算
```

### 7.5 期初数据

标识：

```text
source_type = OPENING
is_opening = 1
```

范围：

```text
期初合同
期初账单
期初已收
期初欠费
期初押金
```

规则：

```text
期初欠费不计入当期收缴率
期初回收单独统计
期初回款正常不审批
期初冲正/退款按金额审批
冲正/退款必须关联原期初收款
部分冲正/退款累计不能超过原收款
```

### 7.6 财务报表

```text
本期应收

本期收缴率
期初欠费
期初回收
期初回收率
期初冲正
期初退款
当期欠费
总欠费
```

## 14. 验收标准

```text
1. 超过 20 条选择器可搜索
2. 层级选择必须树形/级联
3. 大数据选择必须弹窗分页
4. 三个标准页面完整闭环
5. 申请、合同、退租有草稿
6. 审批支持单级/多级/平行 and/or
7. 金额类无模板也强制审批
8. 合同无模板直通有权限和日志
9. 财务数据范围按组织树
10. 项目管理员不能跨项目看人员
11. 五级地址中文项目强制
12. 期初欠费不计入当期收缴率
13. 批量操作有影响提示和结果
14. 每个业务对象有详情和下一步动作
15. 列表不显示裸 ID 和英文编码
16. 每个操作有审计日志
```
