# 保障房标准页面与页面模板阶段设计

> 阶段：标准页面设计第一阶段  
> 依据：多场景平台总体设计基线 v1.1、保障房菜单结构设计  
> 状态：阶段性设计文档，尚未进入页面编码  
> 日期：2026-11-09

---

## 1. 阶段目标

在三张标准页面基础上，建立可复用的页面模板体系，避免 40 个菜单页面各写一套。

本阶段要解决：

```text
哪些页面是标准样板
每类页面由哪些区域组成
页面之间复用哪些组件
每个页面必须验证哪些业务能力
后续详细设计如何展开
```

本阶段不解决：

```text
完整视觉稿
完整接口定义
完整数据库变更
页面编码实现
```

---

## 3. 页面模板总则

### 3.1 所有页面共同要求

```text
支持项目/场景上下文
支持数据范围权限
支持字段权限和脱敏
支持加载态、空态、错误态
支持操作反馈
支持审计留痕
不显示裸 ID
不显示英文枚举
```

### 3.2 页面结构约定

```text
页面标题区
筛选/上下文区
主内容区
操作区
详情/弹窗/抽屉
```

### 3.3 页面行为约定

```text
列表不直接编辑所有字段
详情页承担完整信息和主要动作
办理页承担流程动作
危险操作二次确认
批量操作显示影响范围
操作成功/失败有明确反馈
```

### 3.4 菜单与页面关系

```text
菜单只进入列表/任务/看板/工作台/配置
详情不作为菜单
新增/编辑/删除不作为菜单
审批动作在详情或任务页内完成
```

## 4. T1 工作台模板

### 4.1 适用页面

```text
运营驾驶舱
后续物业驾驶舱
资产经营驾驶舱
```

### 4.2 页面区域

```text
顶部上下文
├─ 项目
├─ 场景
├─ 时间范围
└─ 刷新

第一层：KPI
├─ 房源
├─ 申请
├─ 合同
├─ 收费
├─ 设备
└─ 告警/待办

第二层：图表
├─ 房源结构
├─ 账单趋势
├─ 收缴率
├─ 设备类型/状态
└─ 业务漏斗

第三层：待办与异常
├─ 待审批
├─ 逾期账单
├─ 未处理告警
└─ 年审到期

第四层：最近业务
├─ 最近合同
├─ 最近收款
└─ 最近事件
```

### 4.3 交互要求

```text
KPI 可点击下钻
图表可点击进入筛选列表
待办可直达处理页
时间/项目筛选影响全页
期初和当期分开显示
```

### 4.4 数据要求

```text
指标口径统一
数据范围过滤
期初欠费单独
总欠费包含期初
收缴率只算当期
```

### 4.5 验收重点

```text
驾驶舱不是静态图表
每个数字都能解释来源
每个异常都能进入处理
```

## 7. T4 办理/向导模板

### 7.1 适用页面

```text
申请登记
合同签约
合同变更
退租结算
批量导入
年审发起
```

### 7.2 页面区域

```text
步骤条
├─ 步骤 1
├─ 步骤 2
├─ 步骤 3
└─ 确认提交

表单区
├─ 分组标题
├─ 字段
├─ 选择器
├─ 联动
└─ 校验

底部操作
├─ 上一步
├─ 下一步
├─ 暂存
├─ 提交
└─ 取消
```

### 7.3 草稿要求

```text
创建即草稿
20-30 秒自动保存
字段失焦保存
离开页面提示
再次进入恢复
默认保留 30 天
草稿不进入审批
草稿不生成账单
```

### 7.4 选择器要求

```text
人员：搜索 + 状态过滤
房屋：项目→楼栋→单元→楼层→房屋
合同：合同号/人员/房屋搜索
设备：编码/名称/类型搜索
```

### 7.5 提交与审批

```text
有模板 → 提交审批
无模板且合同类 → 授权角色可直通
无模板且金额类 → 强制审批
提交后进入对应详情
```

### 7.6 验收重点

```text
断网/刷新可恢复
校验具体到字段
步骤可回退
提交前有确认
不重复提交
```

## 12. 页面模板与核心目标映射

| 目标 | 模板体现 |
|---|---|
| 多场景可扩展 | 模板与业务解耦，场景配置决定字段/菜单 |

| 稳定高效可运维 | 分页、异步、错误态、任务状态 |
| 可持续交付与演进 | 模板化、组件化、契约化 |
