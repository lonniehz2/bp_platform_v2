## 2. 角色走查结果

原型角色切换后，可见动作如下：

| 角色 | 可见动作 |
|---|---|
| 项目负责人 | 新增申请、无模板生效、合同直接收款、生成账单、设备绑定、设备导入 |
| 窗口受理 | 新增申请 |
| 审核员 | 审核批量通过/退回 |
| 财务 | 合同直接收款、生成账单、账单收款 |
| 设备运维 | 设备绑定、设备导入 |
| 场景管理员 | 全部动作 |

### 2.1 走查发现并修正

| 问题 | 修正 |
|---|---|
| 所有角色都能看到“新增申请” | 限制为窗口、项目负责人、场景管理员 |
| 所有角色都能看到“设备导入” | 限制为设备运维、项目负责人、场景管理员 |
| 所有角色都能看到“生成账单” | 限制为财务、项目负责人、场景管理员 |
| 所有角色都能看到“合同变更” | 限制为项目负责人、场景管理员 |
| 所有角色都能看到“账单减免” | 限制为财务、项目负责人、场景管理员 |
| 审核员也能看到“转轮候” | 限制为窗口、项目负责人、场景管理员 |

### 2.2 剩余说明

```text
原型没有实现菜单级角色过滤
正式页面必须同时做菜单可见性和动作权限
菜单可见不等于数据可见
```

## 3. 合同直接收款：确认采用“先选账单，再收款”

### 3.1 交互

```text
合同详情 → 直接收款
→ 打开收款抽屉
→ 展示合同下未结清账单
→ 选择账单
→ 填写收款信息
→ 确认收款
→ 生成收据
```

### 3.2 账单选择

```text
默认展示未结清账单
按账期倒序
显示账单号、账期、应付、已收、未收、状态
支持单笔选择
支持多笔选择
支持按未收金额分配
```

### 3.3 默认规则

```text
只有一笔未结清账单 → 默认选中
多笔未结清账单 → 不默认全选，提示选择
没有未结清账单 → 禁用直接收款，提示“无未结清账单”
```

### 3.4 金额规则

```text
默认收款金额 = 选中账单未收金额合计
允许修改
收款金额不能超过选中账单未收合计
多账单收款必须生成分配明细
部分收款允许
```

### 3.5 权限

```text
guarantee:contract:pay
guarantee:billing:pay
```

可见角色：

```text
财务
项目负责人
场景管理员
```

窗口受理默认不直接收款。

### 3.6 复用

```text
不复制收款逻辑
调用账单收费统一收款接口
收据由账单收费服务生成
合同详情只做上下文和账单选择
```

## 4. 申请转轮候：确认角色和条件

### 4.1 可见角色

```text

```

不可见：


### 4.2 条件

```text

未进入轮候
当前项目在授权范围
有 guarantee:application:waitlist 权限
```

```text

写操作日志

```

### 4.4 数据范围

```text
窗口：本项目
项目负责人：本项目
场景管理员：场景内
```

## 5. 设备继承来源：确认展示方式

### 5.1 树节点

```text
空间名称
直绑设备数
继承设备数
```

示例：

```text
101室  直绑 1  继承 2
```

### 5.2 继承设备列表

列：

```text
设备编码
设备名称
设备类型
来源空间
来源路径
继承层级
状态
```

示例：

```text
DV202611001
101门锁
门锁
A栋
A栋 / 1单元 / 1层
第 3 层继承
在线
```

### 5.3 展示规则

```text
直绑设备标记“直绑”
继承设备标记“继承自 A栋”
来源空间可点击

当前节点直绑的设备不出现在继承列表
一个设备只出现在一个来源空间
```

### 5.4 接口字段

```text
sourceSpaceId
sourceSpaceName
sourcePath
inheritLevel
bindType = DIRECT / INHERITED
```

## 6. 驾驶舱时间范围与期初/当期口径

### 6.1 时间维度

驾驶舱按**账期**筛选，不按创建时间：

```text
本月
本季
本年
自定义账期范围
```

默认：

```text
本月账期
```

### 6.2 指标定义

```text
本期应收 = 账期范围内非期初账单的应付合计
本期实收 = 这些账单的已核销金额
本期收缴率 = 本期实收 / 本期应收
当期欠费 = 本期应收 - 本期实收
期初欠费 = 期初账单未收金额
总欠费 = 期初欠费 + 当期欠费
期初回收 = 期初账单在范围内收回的金额
期初回收率 = 期初回收 / 期初欠费
```

### 6.3 展示规则

驾驶舱分开显示：

```text
本期应收
本期实收
本期收缴率
期初欠费
期初回收
期初回收率
当期欠费
总欠费
```

不能只显示一个“欠费”。

### 6.4 下钻

```text
点击本期收缴率 → 带入账期范围，只看非期初账单
点击期初欠费 → 只看期初账单
点击总欠费 → 期初 + 当期分开展示
```

### 6.5 口径约束

```text
期初欠费不计入本期收缴率
本期实收按账单归属期统计，不按收款日期
收款现金流如需单列，另设“本期收款金额”
```
