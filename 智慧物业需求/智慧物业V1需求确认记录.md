# 智慧物业 V1 需求确认记录

> 用途：记录设计阶段新增/变更需求，避免后续编码遗漏。

| 编号 | 日期 | 需求 | 设计处理 | 状态 |
|---|---|---|---|---|
| R1 | 2026-11-08 | 人员信息包含人脸照片（非必需） | 人员档案增加 `face_photo_url` 可空字段；支持上传/预览/替换/移除；仅在详情和审核详情展示；本期只存档，不做人脸识别、不做门禁下发 | 已纳入设计 |

## R1 说明

### 字段

```text
bp_person.face_photo_url   可空
或
prop_person_ext.face_photo_url
```

### 规则

```text
非必填，不阻塞人员建档
只存文件服务 URL，不存 base64
支持 JPG/PNG，建议不超过 2MB
支持上传、预览、替换、移除
仅在人员详情、审核详情展示
列表不展示照片缩略图
本期只做照片存档，不做人脸识别、不做门禁下发
后续对接 IOT 时再定义人脸下发、同步、删除规则
```

### 接口

```text
POST /files/upload
POST /persons
PUT  /persons/{id}
GET  /persons/{id}
```

### 权限

```text
查看：property:person:view
上传/替换/移除：property:person:edit
审核查看：property:review:view
```

### 涉及页面

```text
客户与人员 → 人员档案
审核中心 → 业主审核
审核中心 → 实名审核
```
