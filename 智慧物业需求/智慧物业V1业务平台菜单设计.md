# 智慧物业 V1 业务平台菜单设计

> 版本：V1.2 范围裁剪版  
> 范围：只包含智慧物业业务平台，不包含 IOT 设备平台和智慧停车系统  
> 说明：停车已有分析结果和已实现代码保留，但暂不进入本期业务平台菜单，后续按独立系统需求细化
>
> 进一步结合 `云门道智慧云功能菜单设计V5.1D.xls` 的优化版见 [智慧物业V1业务平台菜单设计-结合V5.1D优化版](智慧物业V1业务平台菜单设计-结合V5.1D优化版.md)。

### 1.3 与外部系统的关系

业务平台不重复建设 IOT 和停车，只保留接口边界：

```text
IOT 平台
  → 提供表计读数、设备状态、告警事件
  → 业务平台只消费抄表读数、能耗数据

智慧停车
  → 独立管理车位、车辆、停车订单、车闸
  → 向业务平台提供停车收入/停车费账单接口
  → 业务平台不展示停车操作菜单
```

本期设计不包含上述接口的具体实现，只预留对接位置。

## 3. 菜单职责

### 3.1 工作台

| 菜单 | 职责 |
|---|---|
| 运营驾驶舱 | 物业公司/区域多项目经营总览、项目排名、收入、收缴率、欠费、合同、能耗成本、工单、投诉 |
| 项目工作台 | 当前项目日常作业台、今日待办、快捷入口、项目 KPI、合同/账单/工单提醒 |
| 我的待办 | 合同到期、欠费催缴、优惠审批、退款审批、工单、回访 |
| 消息中心 | 站内信、短信、微信发送记录、失败重发 |
| 统一查询 | 人员、房屋、合同、账单、工单、车牌统一检索，按项目和权限过滤 |
| 到期与异常提醒 | 合同到期、账单逾期、抄表异常、公摊异常；不包含设备告警 |

### 3.2 项目与资产

| 菜单 | 职责 |
|---|---|
| 项目管理 | 物业公司/区域/项目层级、项目五级地址、项目状态 |
| 空间层级 | 项目 → 楼栋 → 单元 → 楼层 → 房间/商铺/办公 |
| 房屋台账 | 住宅、商铺、办公、仓库、建筑面积、套内面积、交付状态 |
| 资产台账 | 公共资产、经营资产、资产使用状态；不含 IOT 设备 |
| 项目收费区域/楼栋参数 | 收费区域、默认收费标准、交付批次、楼栋参数 |

### 3.3 客户与人员

| 菜单 | 职责 |
|---|---|
| 业主与住户 | 房屋与业主、家人、承租人、同住人关系、主业主 |
| 业主审核 | 业主身份、房屋关系、资料审核 |
| 人员档案 | 人员主档、证件、联系方式、实名状态、人脸照片（非必填，仅存档） |
| 人员组管理 | 按楼栋、单位、类型、标签分组 |
| 服务人员管理 | 保洁、维修、客服等服务人员档案；不含 IOT 授权 |
| 实名核验 | 实名核验记录、失败原因、人工复核 |
| 入住管理 | 房间、入住人、入住时间、退住；适用于公寓/宿舍项目 |
| 访客登记 | 访客登记、被访房屋、来访时间；不做门禁授权 |

### 3.4 合同与租赁

| 菜单 | 职责 |
|---|---|
| 租赁合同 | 商铺、车位、场地、广告位、办公租赁合同 |
| 租客管理 | 租客档案、联系方式、合同关联 |
| 出租记录 | 房屋/商铺出租历史、租金、租期 |
| 合同变更 | 租金、面积、租期、付款方式变更 |
| 调铺/换房 | 商铺调换、房屋调整 |
| 退租管理 | 退租申请、费用结算、押金退款 |
| 合同到期提醒 | 30/60/90 天到期、续租办理 |

停车位租赁本身由智慧停车系统负责；如果后续需要把车位租赁合同纳入统一合同台账，只保留合同接口，不在本期菜单中展开。

### 3.5 收费与账务

| 菜单 | 职责 |
|---|---|
| 收费项目 | 按类别维护：物业费、能耗费、水费、电费、车位管理费、租金、其他 |
| 计费方案 | 按项目/楼栋/房屋配置单价、周期、生效日期、自动出账 |
| 账单管理 | 批量出账、账单明细、优惠、发布、取消 |
| 收款管理 | 现金/转账/POS/微信/支付宝、分摊、收据 |
| 优惠与补贴 | 物业优惠、减免、补贴抵扣、审批 |
| 押金与退款 | 租赁押金、装修押金、钥匙押金、退款审批 |
| 电子发票 | 发票申请、开票、下载、失败重开 |
| 欠费催缴 | 欠费清单、短信/微信/邮件催缴、任务记录 |
| 资金流水 | 收款、退款、补贴、押金流水 |
| 收据查询 | 电子收据查询、PDF 下载、验真 |

停车费账单如果由智慧停车系统产生，本期只考虑通过外部账单接口汇入，不单独建设停车收费菜单。

### 3.6 计量与能耗

| 菜单 | 职责 |
|---|---|
| 表计档案 | 水表、电表档案、表号、倍率、单价、缴费户号 |
| 抄表管理 | 手工抄表、导入 IOT 读数、抄表记录、异常复核 |
| 公摊分摊 | 项目/楼栋公摊、按面积分摊、生成账单 |
| 能耗分析 | 用量趋势、同比环比、异常用量、能耗成本 |

表计档案只做业务台账；远程拉闸、日冻结、换表操作、设备通信属于 IOT 平台。

### 3.7 服务与监督

| 菜单 | 职责 |
|---|---|
| 工单维保 | 报修、派单、处理、回访、超时 |
| 投诉建议 | 投诉、建议、处理、回访 |
| 入户走访 | 走访计划、记录、异常上报 |
| 公告通知 | 物业公告、停水停电、缴费通知 |
| 业主投票 | 业主议题、投票、结果统计 |
| 联系物业/反馈 | 业主留言、APP/小程序反馈 |
| 服务评价 | 工单/投诉满意度、评价统计 |

设备告警、门禁记录不在本期服务菜单中，由 IOT 平台负责。

### 3.8 经营分析

| 菜单 | 职责 |
|---|---|
| 项目利润表 | 收入、支出、利润、收缴率 |
| 收缴率分析 | 按项目/楼栋/费用类型统计 |
| 欠费分析 | 账龄、欠费户、催缴效果 |
| 合同收入分析 | 商铺/场地/广告位租金收入 |
| 能耗成本分析 | 水电成本、公摊成本、单位面积成本 |
| 人员结构统计 | 业主/租户/服务人员结构 |
| 报表导出 | Excel/CSV 导出、报表订阅 |

### 3.9 系统与数据

| 菜单 | 职责 |
|---|---|
| 组织机构 | 物业公司、区域公司、项目、服务处 |
| 用户与权限 | 用户、角色、权限、项目数据范围 |
| 人员类型 | 业主、家人、承租人、同住人、访客、服务人员 |
| 岗位管理 | 项目经理、客服、收费、财务、工程等岗位 |
| 菜单/会话 | 菜单配置、在线会话、强制下线 |
| 行政区划与字典 | 五级区划、收费分类、合同类型、人员类型 |
| 消息模板与通道 | 短信/微信模板、通道配置、发送记录 |
| 外部系统对接 | IOT 平台、智慧停车、税控、支付、短信/微信接口配置 |
| 操作日志 | 账单、收款、退款、折扣、权限操作日志 |
| 平台信息 | 公司信息、LOGO、收据抬头、开票信息 |
| 使用帮助 | 操作手册、流程说明、字段说明 |

## 4. 核心流程

### 4.1 项目初始化

```text
创建物业公司
→ 创建区域/城市公司
→ 创建物业项目（五级地址）
→ 创建空间层级
→ 导入房屋台账
→ 导入人员
→ 建立业主/承租人关系
→ 配置收费项目
→ 配置计费方案
→ 开始出账
```

### 4.2 业主/住户入住

```text
人员档案
→ 实名核验
→ 选择房屋
→ 建立业主/家人/承租人/同住人关系
→ 主业主确认
→ 生成首期账单
```

门禁授权不在本期流程内，由 IOT 平台处理。

### 4.3 租赁合同

```text
选择租赁标的
→ 填写承租方、租期、租金、押金
→ 合同审批
→ 合同生效
→ 收取押金
→ 生成租金账单
→ 合同变更/调铺/退租
→ 退租结算与押金退款
```

### 4.4 物业费出账

```text
计费方案
→ 批量生成账单
→ 优惠/补贴计算
→ 账单发布
→ 收款
→ 生成 PDF 收据
→ 电子发票
→ 欠费催缴
```

### 4.5 水电与公摊

```text
表计档案
→ 手工抄表/导入 IOT 读数
→ 用量计算
→ 水电账单
→ 公摊总额录入
→ 按面积分摊
→ 生成公摊账单
→ 收款
```

### 4.6 服务工单

```text
业主/客服报修
→ 工单受理
→ 派单
→ 处理
→ 回访
→ 评价
→ 归档
```

## 9. 设计结论

本期业务平台收敛为 **9 个一级菜单**：

```text
工作台
项目与资产
客户与人员
合同与租赁
收费与账务
计量与能耗
服务与监督
经营分析
系统与数据
```

IOT 设备平台和智慧停车系统不进入本期业务平台菜单：

- IOT 设备台账、设备绑定、通行、卡片、告警、远程控制不纳入。
- 停车管理、车位、车辆、停车订单、车闸、停车券不纳入。
- 已在业务平台实现的停车代码和数据保留，后续迁移/独立为智慧停车系统。
- 业务平台只保留表计读数、停车收入/账单等接口边界。

这样业务平台聚焦“项目、人、房、合同、收费、服务、报表”，IOT 和停车各自独立演进，避免系统边界混乱。
