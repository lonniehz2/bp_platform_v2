# 智慧物业 V1 核心页面结构稿

> 配套文件：`智慧物业V1菜单-路由-页面-权限-复用对照表.xlsx`  
> 目的：在编码前确认页面布局、字段、操作和角色差异，减少返工  
> 范围：不含 IOT 设备平台、智慧停车  
> 说明：本稿是结构稿，不是最终视觉稿；沿用现有 Element Plus 风格

---

## 1. 全局框架

```text
┌────────────────────────────────────────────────────────────────────┐
│ 顶部栏：项目选择器 | 当前用户 | 返回保障房 | 语言 | 退出              │
├──────────────┬─────────────────────────────────────────────────────┤
│ 左侧菜单      │ 页面标题 / 面包屑 / 页面级操作按钮                    │
│ 11 个一级菜单 │                                                     │
│              │ 内容区：筛选 + KPI + 列表 / 表单 / 详情              │
│              │                                                     │
└──────────────┴─────────────────────────────────────────────────────┘
```

全局规则：

```text
左侧菜单宽度 220px，可折叠
顶部项目选择器全局生效
切换项目刷新当前页面数据
所有列表默认带项目上下文
无权限菜单不显示，无权限按钮禁用或隐藏
```

人员信息字段：

```text
姓名                 必填
性别                 非必填
手机号               必填
证件类型/证件号      按业务需要
人员类型             业主/家人/承租人/同住人/临时人员/访客/服务人员/物业员工/供应商人员
实名状态             未核验/已核验/失败/过期
人脸照片             非必填，JPG/PNG，建议 ≤2MB
房屋关系             通过 prop_owner_unit 维护
附件                 身份证、证明文件
备注
```

人脸照片规则：

```text
非必填，不阻塞人员建档
只存文件地址，不存 base64
支持上传、预览、替换、移除
仅在人员详情和审核详情展示
列表不展示照片缩略图
本期只做照片存档，不做人脸识别、不做门禁下发
后续对接 IOT 时再定义人脸下发、同步、删除规则
```

字段建议：

```text
bp_person.face_photo_url  可空，存文件服务 URL
或 prop_person_ext.face_photo_url
```

接口：

```text
POST /files/upload           上传照片
POST /persons                人员新增，携带 facePhotoUrl
PUT  /persons/{id}           修改，可替换或清空
GET  /persons/{id}           详情返回 facePhotoUrl
```

权限：

```text
查看照片：property:person:view
上传/替换/移除：property:person:edit
审核查看：property:review:view
```

隐私：

```text
人脸照片按敏感信息管理
访问需要权限
人员删除/注销时按策略清理
不对外公开，不进入普通导出
```

## 7. 计费方案

### 7.1 页面定位

替代“每户一份物业合同”，按项目/楼栋/房屋配置自动出账方案。

### 7.2 页面结构

```text
┌──────────────────────────────────────────────────────────────┐
│ 计费方案                                    新增计费方案      │
├──────────────────────────────────────────────────────────────┤
│ 方案名称 | 收费项目 | 范围 | 单价 | 周期 | 生效期 | 状态      │

│ 操作：编辑 / 停用 / 预览 / 立即出账                           │
└──────────────────────────────────────────────────────────────┘
```

新增向导：

```text
第 1 步：选择范围
  项目 / 楼栋 / 单元 / 房屋

第 2 步：选择收费项目
  物业费 / 水费 / 电费 / 租金 / 其他

第 3 步：设置价格和周期
  单价、计费周期、生效日期、结束日期

第 4 步：预览
  预计房屋数、预计金额
  确认保存 / 保存并启用
```

规则：

```text
同一范围、同一收费项目、同一时间不能重复生效
方案停用后不再生成新账单
历史账单不受影响
```

## 12. 当前结论

建议先确认：

```text
1. 11 组菜单是否最终确认
2. 空间结构模板是否按项目选择
3. 审核中心是否独立
4. 计费方案是否替代默认合同
5. 停车/IOT 是否继续隐藏
```

确认后再进入编码，按“菜单壳 → 项目/空间 → 审核 → 计费/账单/收款”的垂直切片推进。
