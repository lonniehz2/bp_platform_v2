## 附录 CD　金额格式收尾与监管报送性能（第 16/17 轮）

### 金额格式（续）

补充统一 `$money` 的页面/列：

| 页面 | 列 |
|---|---|
| 资金流水 | 系统金额、渠道金额、收款金额、可核销余额 |
| 短租订单 | 金额 |
| 补贴标准 | 补贴值、封顶金额 |
| 退租管理 | 月租、押金 |
| 账单/催缴 | 抄表金额、单价、待缴 |

实测退租：月租 `1,830.00`、押金 `1,800.00`。

### 监管报送超时（真实缺陷）

现象：发起监管报送（HOUSE）等待超过 300 秒；演示数据 6,377 套房源，逐条写报送明细。

处理：

1. 明细改为 JDBC 批量写入（失败时回退 MyBatis-Plus 批处理）
2. 单次报文上限 500 条，超出时任务备注：「数据总量 6377 条，单次最多报送 500 条…请按范围分批」
3. 实测：请求耗时 300s+ → **20.7s**，记录 500 条，备注明确

管线 16 项全部通过（旅程 12 不再超时）。
