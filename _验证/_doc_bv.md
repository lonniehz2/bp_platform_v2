## 附录 BV　账单可解释性：费用区间与重算预览（第 7 轮）

| 项 | 内容 |
|---|---|
| 费用区间列 | 账单列表新增「费用区间」（periodStart ~ periodEnd），可核对为何按某段天数计费 |
| 重算先试算 | 「重算历史账单」先调 `dryRun`，弹出「扫描 271、需重算 175、合计 8273.00 → 1156.45」确认后才落库；无差异时直接提示，不弹确认 |
| 账单备注 | 新生成的自动账单备注写入「计费 X 天（9月21/30 + 10月10/31）」；重算账单备注追加「按新规则重算：旧 → 新（计费 X 天）」 |
| 幂等 | 再次试算变更 0 |

实测：账单表头含「费用区间」；样例账单 `2026-09-28 ~ 2026-09-29`；重算按钮存在且先试算。
