## 附录 CK　深色模式（2026-10-30）

### 一、使用方式

- 顶部工具栏图标按钮（月亮/太阳）一键切换浅色 / 深色；
- 选择保存在浏览器（`bp.ui.mode`），刷新、重新登录后保持；
- 默认浅色；后续平台可配置默认配色与「是否允许用户切换」。

### 二、实现要点

- `uiState.mode` 控制 `html.dark`，Element Plus 深色变量 + 平台自定义 CSS 变量；
- 统一变量：`--bp-page-bg`、`--bp-card-bg`、`--bp-sider-bg`、`--bp-header-bg`、`--bp-hover-bg`、`--bp-sider-active-bg`；
- 表格头、卡片、弹窗、抽屉、图表、侧边栏菜单均按变量适配；
- 页面内写死的白底/深灰字统一替换为 Element 变量（Dashboard、Help、Todos、PlatformInfo 等）；
- 图表（SVG/ECharts）按容器背景自动选择文字颜色。
