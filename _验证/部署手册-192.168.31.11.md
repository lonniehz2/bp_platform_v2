### 2.1 Redis 配置要点

配置文件 `/etc/redis/redis.conf`（原文件备份为 `.bak.orig`）：

```
bind 0.0.0.0 -::1
protected-mode yes
requirepass bpRedis2026
maxmemory 512mb
maxmemory-policy allkeys-lru
```

- **限内存 512MB**：8GB 机器上避免挤占 JVM
- **已验证**：带密码 `PING` → `PONG`；无密码 → `NOAUTH Authentication required`（符合预期）

### 2.2 RabbitMQ 配置要点

- 新建用户 `bp`（administrator tag），权限对 `/` vhost 全开
- 启用 `rabbitmq_management` 插件 → 管理台 `http://192.168.31.11:15672`
- 内置 `guest` 账户仍保留（仅限 localhost，未改动策略）

## 三、应用部署细节

### 3.1 目录结构

```
/opt/bp-platform/
  └ bp-platform.jar          45 MB（属主 bp，权限 640）
/etc/bp-platform.env         环境变量（含密码，权限 600，root:root）
/etc/systemd/system/bp-platform.service
/var/log/bp-platform/
  ├ app.log
  └ err.log
```

### 3.2 环境变量文件 `/etc/bp-platform.env`

```bash
# 数据库（独立 MySQL 服务器）
BP_DB_HOST=192.168.31.153
BP_DB_PORT=33306
BP_DB_USER=root
BP_DB_PWD=5677@Mysql
BP_DB_NAME=bp_platform

# Redis（本机）
BP_REDIS_HOST=127.0.0.1
BP_REDIS_PORT=6379
BP_REDIS_PWD=bpRedis2026

# RabbitMQ（本机）
BP_MQ_HOST=127.0.0.1
BP_MQ_PORT=5672
BP_MQ_USER=bp
BP_MQ_PWD=bpMq2026

BP_HEALTH_DB=false           # DB 探针默认关，避免启动阻塞
BP_WORKER_ID=1
BP_DATACENTER_ID=1

# IoT 凭证（待填）
YMD_APP_ID=
YMD_APP_SECRET=
```

> ⚠️ 该文件含明文密码，权限已设为 **600 root:root**，应用以 `bp` 用户通过 systemd 读取。

### 3.3 systemd 单元要点

```ini
[Service]
User=bp
EnvironmentFile=/etc/bp-platform.env
ExecStart=/usr/bin/java -Xms512m -Xmx1024m -XX:+UseG1GC \
          -Dfile.encoding=UTF-8 -jar /opt/bp-platform/bp-platform.jar \
          --server.port=8080
Restart=on-failure
RestartSec=10
StandardOutput=append:/var/log/bp-platform/app.log
NoNewPrivileges=true
PrivateTmp=true
ProtectSystem=full
ProtectHome=true
```

- **堆内存 512M~1024M**（VM 总 7.8GB，够用且留余量）
- **安全加固**：`NoNewPrivileges`、`PrivateTmp`、`ProtectSystem`、`ProtectHome`
- **自动重启**：`Restart=on-failure`

## 六、注意事项与已知限制

| # | 事项 | 说明 |
|---|---|---|
| 1 | **`luo` 不在 sudo 组** | 所有 root 操作需 `su - root -c '...'`（root 密码有效）。如需便捷可 `usermod -aG sudo luo` |
| 2 | **root 不可 SSH** | 按原安全配置保留 |
| 3 | **RabbitMQ 暂无队列/连接** | 应用代码尚未实现 MQ 消费者，属预期状态 |
| 4 | **Redis 暂无业务 key** | 应用代码尚未实现缓存逻辑，属预期状态 |
| 5 | **未配置 TLS/HTTPS** | 测试环境，生产需加 nginx 反代 + 证书 |
| 6 | **数据库密码在 env 文件中明文** | 生产应改用密钥管理（Vault/KMS）或容器 Secret |
| 7 | **未配置日志轮转** | 长时间运行需加 `logrotate`，否则日志会持续增长 |
| 8 | **IoT 凭证未填** | `YMD_APP_ID` / `YMD_APP_SECRET` 为空，IoT 相关功能不可用 |

### 6.1 建议的后续加固

```bash
# 1) 日志轮转
cat > /etc/logrotate.d/bp-platform <<'EOF'
/var/log/bp-platform/*.log {
    daily
    rotate 14
    compress
    missingok
    notifempty
    copytruncate
}
EOF

# 2) 给 luo 加 sudo（可选）
usermod -aG sudo luo

# 3) 释放桌面内存（可选，需重启）
systemctl set-default multi-user.target
```
