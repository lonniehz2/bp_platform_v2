## 附录 CP　收款单入口与核销体验（2026-10-31）

**问题**：账单核销要求填「收款单ID」，但业务系统没有收款单列表入口，用户无法获知 ID。

**修复**：

| 位置 | 变化 |
|---|---|
| 账单与缴费 工具栏 | 新增「收款单」按钮：打开收款单列表（单号、缴费人、收款金额、已核销、余额、状态、收款时间、总数、翻页） |
| 登记收款 | 成功后提示「收款已登记：FP…（可在「收款单」查看）」 |
| 账单核销 | 「收款单ID」文本框改为下拉选择（单号 · 缴费人 · 余额），只列余额 > 0 的收款单；无单时提示先去登记收款 |
| 收款单缴费人 | 登记未填姓名时按人员档案回填；列表与下拉兜底显示人员名称/ID |

**操作路径**：账单与缴费 → 登记收款（生成收款单）→ 收款单（查看单号）→ 账单行「核销」→ 选择收款单 → 确认核销。

实测：收款单列表 6668 条，表头与分页正常；核销弹窗出现收款单下拉与引导文案。
