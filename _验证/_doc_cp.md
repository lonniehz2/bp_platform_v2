## 附录 CP　M1：规则自动匹配与实际人口/床位计费（2026-10-31）

### 一、规则方式

批量出账新增「计费规则」：

| 方式 | 说明 |
|---|---|
| 自动匹配（默认） | 按收费项目 + 组织 + 房源类型 + 保障类型 + 生效期 + 优先级匹配 |
| 指定规则 | 人工选择该收费项目下已审批规则，留痕 |
| 不使用 | 按收费项目单价 |

- 账单保存 `rule_id、rule_version、rule_snapshot`，规则后续修改不影响历史解释；
- 规则配置兼容 `rate` 与历史 `ratio` 两种折扣写法；
- 同分时优先组织专属，再取较新规则。

### 二、实际人口/床位

- 保障人口 = 承租人 1 + 同住人，实时取数并快照到账单；
- 床位 = 合同实际床位数，默认 1，不再取房源 `maxCapacity`；
- 合同详情展示计费人口/床位；
- 仅“整套/面积/固定”租金用合同月租覆盖；按人/按床/按夜租金按项目单价×数量。

### 三、验证

| 场景 | 结果 |
|---|---|
| 合同月租 900，手工 8 折规则 | 720.00 |
| 自动匹配组织专属 8 折 | 720.00（规则：A工作按套8折） |
| 2 人按人计费 10 元 | 数量 2、金额 20.00 |
| 2 床按床计费 10 元 | 数量 2、金额 20.00 |
| 落库账单快照 | rule_id、rule_version、rule_snapshot、billing_quantity 均写入 |
| 一键验收管线 | 16 项全部通过 |
